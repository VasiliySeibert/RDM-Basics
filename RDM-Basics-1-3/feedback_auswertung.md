## Overview

This presentation evaluates participant feedback from the first pilot run of "RDM Basics for Engineers" conducted with Hochschule RheinMain. It covers feedback from two talks.

---

## Vortrag 1: Fundamentals of RDM (M. Moser)

### Participation
- 11 participants at the talk, including M. Moser, K. Diester, and Prof. Eissler
- QR code and links to the survey (EN and DE) were provided at the end of the talk
- **7 complete responses** received

### Helpfulness
- Generally positive ratings
- One participant who rated it "less helpful" already had prior knowledge and therefore found it less useful

### Understandability
- Results presented (slide contained chart -- generally positive)

### Take-aways
Participants were asked: *"What is one thing you learned or took away from the talk?"*

- FAIR
- "Heute war noch nichts neues, aber ich bin gespannt auf die naechsten Wochen" (Nothing new today, but looking forward to the next weeks)
- Kritisches Bewerten von bereitgestellten Datensaetzen (Critical evaluation of provided datasets)
- ORCID als Personenbezogene ID; Lizenzen verstaendlich erklaert (ORCID as person-related ID; licenses explained clearly)
- All metadata has to be stored, together with software (with version), which was used to generate it
- "Es ist eine weites Feld, ich bin nicht allein und kann Unterstuetzung erhalten." (It's a wide field, I'm not alone and can get support)

### Open Questions
Participants were asked: *"What is still unclear after the talk, or where would you like more information?"*

- How to handle software that was used to analyze numerical and experimental data
- Moeglichkeiten der Veroeffentlichung in Bezug auf die Dateigroesse (Publication options regarding file size)
- Structure of whole data: directory structure? readme file in each directory? how big should a readme be?
- Was ist Datenqualitaet und welche Datenqualitaet ist fuer eine spaetere Nutzung (durch wen auch immer) erforderlich? (What is data quality and what quality is required for later use?)

### Enhancement Suggestions
Participants were asked: *"What could be improved about the talk or the format?"*

- "Fuer mich optimal" (Optimal for me)
- "Das wird erst nach den weiteren Veranstaltungen klar werden." (This will only become clear after the further events)

## Key Insights

### What Worked Well
- FAIR principles and licenses were explained clearly
- Participants appreciated learning they can get support
- The practical relevance (ORCID, metadata, critical dataset evaluation) resonated

### Areas for Future Sessions to Address
- Software handling for data analysis (numerical + experimental)
- File size considerations for publication
- Directory structures and README best practices
- Data quality requirements for reuse
